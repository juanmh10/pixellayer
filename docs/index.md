# PixelLayer documentation

PixelLayer 0.5.1 processes images locally through a Rust engine, JSON CLI and stdio
MCP server. The agent skill explains installation and how to use the tools.

| Guide | Contents |
| --- | --- |
| [Installation](installation.md) | Verified Windows download, setup, model and cache |
| [Clients](clients.md) | Selected-client drafts, MCP activation and workspace scope |
| [Usage](usage.md) | Eight tools, operation parameters, outputs and visual review |
| [Uninstall](uninstall.md) | Remove one program version while preserving cache/settings |
| [Troubleshooting](troubleshooting.md) | Downloads, certificates, MCP startup and input errors |
| [Releases](releases.md) | Download channels, package verification and publication workflow |
| [Licenses](licenses.md) | Project, model, runtime and third-party notices |

Windows x64 is the current public installation target. Linux and macOS native
packages are built in CI; that does not establish validation in every agent.
Copilot configuration templates exist; Copilot validation is deferred.

The released archives correspond to their recorded source commits. Later changes
on the default branch do not modify an existing release or its checksums.
